# 文章笔记输出格式模板（通用结构参考）

> 本文件是自写的通用结构模板，用于说明「知幕 AI」文章笔记的输出外形与组织规则，不包含任何具体视频内容。

## 一、Markdown 外形

```markdown
> 来源链接：[实际 B 站视频链接]
<!-- 本地视频使用：> 来源文件：实际文件名.mp4 -->

# 依据视频内容拟定的文章标题

## 目录

- [1. 第一个主题](#实际生成的标题锚点)
- [2. 第二个主题](#实际生成的标题锚点)
- [AI 总结](#ai-总结)

---

## 1. 第一个主题 [00:00]

- **核心概念**：完整说明这个概念及其意义。
- **原因与机制**：说明视频提出的因果关系。
  - **原因一**：具体解释。
  - **条件或边界**：保留限定条件。
- **关键数据或案例**：保留有信息量的数字、单位、例子和论证。

## 2. 第二个主题

### 有必要时增加的小标题

- **观点标签**：详细解释。
  - **案例**：视频实际提到的例子。
  - **结论**：该案例支持的观点或限制。

---

## AI 总结

一至数段连贯文字，概括全片主旨和推理关系。

**关键结论：**
1. 第一条真正独立的结论。
2. 第二条真正独立的结论。
```

说明：

- 这是结构模板，不是必须填满的固定题目；「原因、案例、关键结论」等项只在视频确有内容时出现。
- 目录条目由程序依据实际标题生成，示例占位锚点不能进入成品。
- 标题时间点有证据才显示；没有时间证据可以不带时间，不得编造。
- 章节数量与每章要点数服从视频信息量，不固定。

## 二、内容组织规则

1. 全文主题归并：同一主题在不同时间出现的内容合并到一个章节；文章用逻辑顺序或主题首次出现顺序。
2. 详细保真：保留有区分度的数据、单位、前提、因果、对比、专有名词和案例；去掉寒暄与无信息量过渡语。
3. 标题与加粗有内容：要点写成「**标签**：解释」，标签必须具体。
4. 归因准确：讲者观点、广告自述与模型归纳可区分，主观判断写成「讲者认为/视频主张/视频举例」。
5. 时间点必须有依据；未知时间不显示。
6. 末尾 AI 总结提炼全片结论及其关系，不逐章复述。
