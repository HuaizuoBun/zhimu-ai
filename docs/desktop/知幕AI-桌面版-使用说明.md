# 知幕 AI 桌面版（Windows）使用说明

版本 1.0.2 · Windows 10/11 x64 · 2026-09-19

## 这是什么

知幕 AI 桌面版：把长视频整理成按主题组织的详细文章笔记。支持两种视频来源——**B 站链接**与**本地视频文件**（YouTube 分析已按产品决定移除）。分析、时间轴、思维导图、字幕与问答都在本机界面完成；模型调用使用你自己的 API Key，仅保存在当前会话中，关闭应用即清除。

安装后双击桌面或开始菜单中的「知幕 AI」即可使用，无需安装 Node.js、npm、Python 或任何开发工具。

## 安装与卸载

- 安装包：`知幕AI-Setup-1.0.2-x64.exe`（见交付目录 `desktop/release-p5-final/`，SHA-256 见 P5 报告）。
- 双击安装（一键、默认按当前用户安装到 `%LOCALAPPDATA%\Programs\zhimu-ai`，不需要管理员权限）。
- 卸载：Windows「设置 → 应用」中找到「知幕 AI」卸载，或运行安装目录下的 `Uninstall 知幕 AI.exe`。卸载不会删除你在 `%APPDATA%` 中的个人数据。

## 基本用法

1. 打开应用，进入「工作台」。
2. 选择来源：
   - **Bilibili**：粘贴 B 站视频链接（bilibili.com 或 b23.tv）。
   - **本地视频**：拖入或选择 MP4/WebM 等视频文件（最大 2GB）。两种来源都可附加 SRT/VTT 字幕文件。
3. 进入「API 设置」：选择服务商（DeepSeek、阿里通义、Gemini、Kimi、豆包、GLM、GPT），粘贴对应平台的 API Key，点击「测试连接」。
4. 回到工作台点击「解析视频 / 上传并开始真实分析」。
5. 分析完成后默认显示「✎ 文章笔记」视图：来源行、可点击目录、编号主题章节、粗体要点、AI 总结。右上角与工具栏可「复制 Markdown」或「导出 .md」；其他标签查看时间轴、思维导图与字幕；右侧聊天可基于视频问答。

## 模式说明

- **多模态开启**：抽帧型服务商（DeepSeek/Kimi/豆包/GLM/GPT）在浏览器内解码画面并抽帧（默认每 5 秒，可设 0.5–60 秒）；通义/Gemini 会把视频流式上传到服务商临时空间做原生音画理解。
- **多模态关闭**：只分析字幕文字，需要 B 站公开字幕或随附 SRT/VTT。
- 模型联网调用仍需要网络；断网时界面可打开，分析请求会给出网络错误。

## 数据与安全

- 视频临时副本存放在系统临时目录（`%TEMP%\zhimu-ai-video`），启动时自动清理遗留文件，完成对象超过 24 小时自动清除；也可随时通过重新分析自然覆盖。
- API Key 只在会话内存中使用，不写入磁盘、日志或文章。
- 本地服务只监听 127.0.0.1 随机端口，带每启动一次的会话凭据校验；外部网页无法访问你的本地数据。

## 已知限制（1.0.0）

- 真实模型生成质量尚未在本轮开发中验证（无真实 Key）：请在设置中填入你自己的 Key 后用短视频实测；未测服务商的表现以实际为准。
- B 站视频可能因权限、登录要求、风控或多段音轨而无法导入，此时请改用本地视频。
- 浏览器抽帧要求视频可被 Chromium 解码（建议 MP4/H.264、WebM）；其他编码请转码后使用或选择原生音画服务商。
- 多段 Range 请求返回完整文件（不是分段 206）。
- 无自动更新、账户、云同步（按第一版范围）。

## 开发者：构建命令

```powershell
npm install            # 安装依赖（含 allow-scripts 批准，见 P0 报告）
npm test               # 网页构建 + 19 项网页测试
npm run desktop:test   # 桌面服务 12 项测试
npm run desktop:build  # 构建 desktop/dist（main/preload/server + 渲染层）
npm run desktop:pack   # win-unpacked 直接运行版
npm run desktop:dist   # NSIS 安装包
npm run lint           # ESLint
```
