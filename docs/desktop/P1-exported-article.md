## 1. 为什么需要 AI Agent [00:00]

- **传统自动化的边界**：依赖预设流程，一旦环境变化流程就会中断，难以处理开放式目标。
- **大模型带来通用推理**：提供了自然语言理解与通用推理能力，让系统第一次可以“听懂任务”。
  - **关键跃迁**：Agent 的核心价值是把“理解”推进到“自主行动”。

## 2. Agent 的四层运行架构 [04:18]

- **感知层**：负责接收文本、图像和环境状态。
- **规划层**：把目标拆解为可执行的步骤与依赖，先定义成功标准，再规划执行路径。
- **行动层与反思层**：行动层调用工具，反思层检查结果并决定是否重试；四层缺一不可。

## 3. 任务规划与动态决策 [10:42]

- **检查点控制错误扩散**：长任务需要阶段性检查点，避免早期偏差被放大。
- **允许重排计划**：面对新证据时应允许重排计划，而非机械执行初始清单。
  - **案例**：演示任务在获得新检索结果后丢弃了两步旧计划，直接进入汇总。

## 4. 工具调用与外部世界 [18:30]

- **工具描述要可验证**：必须清晰限定输入、输出和副作用。
- **高风险动作需人工确认**：权限边界与人工确认是不可逆操作的安全网。
- **调用留痕**：每次调用都应保存结果，供后续推理引用。

## 5. 短期记忆、长期记忆与反馈 [28:15]

- **分层存储**：上下文窗口承担短期工作记忆，向量检索适合按语义召回历史知识。

### 反馈转化为规则

- **可执行规则才有效**：反馈必须转化为可执行规则，才会真正改善下一次表现。

## 6. 从 Demo 到可靠系统 [36:48]

- **窄场景闭环优先**：优先构建窄场景闭环，再逐步扩大自主范围。
- **记录每一步输入输出**：才能定位失败原因。
- **三维评估**：用任务成功率、成本和人工接管率共同评估系统。

## AI 总结

Agent 不是一个更会聊天的模型，而是一套围绕目标持续运行的系统。它用规划拆解复杂性，用工具连接外部世界，用记忆保存上下文，再借助反思和评估不断纠偏。真正可落地的 Agent 应从窄场景闭环开始，并把权限、观测、成本与人工接管设计进系统。

**关键结论：**

1. **闭环系统**：感知、规划、行动、反思四层构成持续运行的认知循环。
2. **落地路径**：从窄场景闭环开始，把权限、观测、成本与人工接管设计进系统。
