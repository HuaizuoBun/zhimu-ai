## 功能

- 视频来源：B 站链接、本地视频（最大 2GB），可附加 SRT/VTT 字幕；无 YouTube。
- 分析输出：按主题组织的详细文章笔记（来源行、可点击目录、编号章节、粗体要点与分级解释、AI 总结），默认视图，支持复制 Markdown 与导出 .md。
- 联动视图：时间轴、思维导图、字幕/画面记录、基于视频的问答。
- 模型：DeepSeek、阿里通义、Gemini、Kimi、字节豆包、智谱 GLM、GPT，使用你自己的 API Key（会话内使用，不落盘）。
- 桌面化：本地服务仅监听 127.0.0.1 随机端口 + 每次启动会话凭据；本地视频流式分片存储；单实例；断网可打开界面。

## 版本内修复

- 1.0.2：顶部导航高亮跟随当前页面（知识库页面高亮「知识库」）。

## 已知限制

- 真实模型生成质量请自行填 Key 用短视频验证（开发期无真实 Key，仅模拟测试通过）。
- B 站视频可能因权限、登录要求、风控或多段音轨无法导入，请改用本地视频。
- 浏览器抽帧要求 Chromium 可解码格式（建议 MP4/H.264、WebM）。
- 无自动更新、账户系统、云同步。
